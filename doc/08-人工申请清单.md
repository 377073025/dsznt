# 人工申请清单

> 版本：v0.1　｜　日期：2026-10-24
> 用途：系统开发不等这些申请，先用模拟数据开发；以下事项由人工去办，办好一项，在 Web「接入状态」页录入凭证，系统自动打开对应能力（见 [07-系统详细设计](07-系统详细设计.md) 第 4 节）。
> 公司注册与经营范围的事暂放，本清单中需要营业执照的事项已标注。
> 费用和耗时为估计值，以各平台实际页面为准。

## 2. 建议办理顺序

| 时间 | 办理 | 说明 |
|------|------|------|
| 第 1 周 | R14、R06、R02、R13（1688） | POC 阶段 A 开工的前提 |

## 3. 逐项说明

### R01 拼多多店铺与主账号

| 项 | 内容 |
|----|------|
| 入口 | 拼多多商家后台（mms.pinduoduo.com）开店 |
| 前置 | 选店铺类型：个人店 / 个体店 / 企业店。要申请开放平台（R07），需要企业店 |
| 材料 | 企业店：营业执照、法人身份证、对公账户或法人银行卡；店铺保证金按类目缴纳 |
| 操作 | 开店 → 完成店铺认证 → 记录**主账号**（开放平台授权只能用主账号） |
| 交给系统 | 店铺名称、店铺 ID；主账号本身不录入系统，只用于 R13 浏览器登录和 R07 授权 |
| 未完成时 | 无法开展；开发阶段使用模拟数据 |
| 已有店铺 | 确认是主账号、确认店铺类型后跳过 |

### R02 1688 采集账号（独立）

| 项 | 内容 |
|----|------|
| 入口 | 1688.com 注册 |
| 为什么独立 | 网页读取有被风控的可能，和采购付款账号分开，出了问题不影响下单 |
| 操作 | 用一个单独的手机号注册淘宝/1688 账号；不绑定支付方式；正常登录浏览几天再用于采集 |
| 交给系统 | 不录入账号密码；只在 R13 中用它登录系统专用浏览器 |
| 未完成时 | 选品无法自动搜货，只能人工粘贴货源链接 |

### R03 1688 采购账号（代发付款用）

| 项 | 内容 |
|----|------|
| 入口 | 1688.com；建议企业买家账号 |
| 操作 | 绑定支付宝（建议企业支付宝）→ 开通代发相关的支付方式（如免密/批量支付，按铺货代发工具要求）→ 在 R09 工具中绑定 |
| 注意 | 系统**不接触**付款：下单和付款由铺货代发工具完成，或人工完成 |
| 交给系统 | 无，只在 R09 工具里绑定 |
| 未完成时 | 代发只能人工下单 |

### R04 飞书企业 / 团队

| 项 | 内容 |
|----|------|
| 入口 | 飞书官网注册，创建企业/团队 |
| 操作 | 创建团队 → 邀请店主、运营等成员加入 → 确认自己是管理员 |
| 可选 | 企业认证（需要营业执照），MVP 阶段非必需 |
| 交给系统 | 无（R05 中使用） |

### R05 飞书自建应用（机器人）

| 项 | 内容 |
|----|------|
| 入口 | 飞书开放平台（open.feishu.cn）→ 开发者后台 → 创建企业自建应用 |
| 操作 | 1. 创建应用，填名称（如「店铺 CEO」）、图标<br>2. 添加应用能力：**机器人**<br>3. 权限管理中开通（名称以控制台为准）：接收与发送单聊/群聊消息、以应用身份发消息、读取与上传消息中的文件、获取用户 ID、获取群信息<br>4. 事件与回调：订阅方式选**长连接**；订阅「接收消息」事件、「卡片回传交互」回调<br>5. 创建版本并发布，由管理员审核通过<br>6. 建一个工作群（如「店铺运营」），把机器人拉进群 |
| 交给系统 | App ID、App Secret；工作群 chat_id（系统可在机器人进群后自动获取）；店主的飞书账号（首次私聊机器人后自动登记，再用初始化命令设为 owner） |
| 未完成时 | 只能用 Web 控制台拍板和上传文件 |
| 待验证 | 卡片回调能否走长连接（POC 项）；不行再办 R12 |

### R06 LLM 模型 API 账号

| 项 | 内容 |
|----|------|
| 入口 | Anthropic Console（console.anthropic.com） |
| 操作 | 注册 → 绑定支付方式并预充值（POC 阶段约 $10）→ **设置月度消费上限**（建议先设 $30）→ 创建 API Key（POC 与正式各一把） |
| **需先确认** | Anthropic 的服务对使用地区和主体有限制，开通前请确认你的公司主体与使用地区在其支持范围内并符合服务条款。如果不满足，需要改用在你所在地区合规可用的模型服务；系统的 LLM 层已做成适配器（07 号第 5 节），切换服务商不影响其他模块，但各智能体效果需要重新评测 |
| 交给系统 | API Key；月预算数值 |
| 未完成时 | 系统只能采集数据，不出分析 |

### R07 拼多多开放平台开发者与应用

| 项 | 内容 |
|----|------|
| 入口 | 拼多多开放平台（open.pinduoduo.com） |
| 前置 | 企业资质（营业执照）；R01 为企业店 |
| 操作 | 1. 注册开发者，完成企业认证<br>2. 创建应用：优先尝试「商家自研」类型；该类型主要面向有开发能力的大商家，小店可能不被批准<br>3. 申请权限包：商品读取、订单读取（订单敏感信息需走多多云）、商品发布（如能申请）<br>4. 审核通过后，用店铺**主账号**授权应用 |
| 预期 | 审核周期和结果不确定，**按「大概率不批」做准备**；本店访客、加购数据即使获批也没有接口 |
| 交给系统 | client_id、client_secret、授权后的 access_token / refresh_token |
| 未批时 | 商品、订单数据走网页读取；上架走铺货代发工具（R09） |

### R08 1688 开放平台开发者与 API 权限

| 项 | 内容 |
|----|------|
| 入口 | 1688 开放平台（open.1688.com） |
| 前置 | 企业实名认证（营业执照） |
| 操作 | 1. 注册开发者并完成企业实名<br>2. 创建应用，用途写「自有店铺选品与货源管理」<br>3. 申请 API：关键词搜索商品、商品详情、以图搜货（拍立淘）、供应商信息<br>4. 铺货 / 分销 / 自动下单类接口属于服务商合作，**本项目不申请**，由 R09 工具完成 |
| 交给系统 | AppKey、AppSecret、access_token |
| 未批时 | 1688 数据走网页读取（限速、有风控风险） |
| 价值 | 获批后选品数据稳定、没有风控问题，是性价比最高的一项申请 |

### R09 铺货代发工具

| 项 | 内容 |
|----|------|
| 候选 | 妙手、店管家、麦爆了、风火递、代发助手王等（03 号文档已列出） |
| 操作 | 1. 选 2 家申请试用<br>2. 每家都验证这几点：能否授权拼多多店铺；能否绑定 1688 采购账号（R03）；是否支持 1688 → 拼多多一键铺货；拼多多订单能否自动推单到 1688 下单；有没有导出功能或接口；收费方式<br>3. 选定一家，正式订阅 |
| 交给系统 | 工具登录方式（系统用 R13 同样的独立浏览器登录工具网页，或工具提供的接口凭证）；验证结果填在本表备注 |
| 未完成时 | 上架只生成物料包让人工上传；代发人工下单；选品打分中「代发自动化」一项记 0 |

### R10 市场数据工具

| 项 | 内容 |
|----|------|
| 候选 | 多多情报通、电霸等 |
| 操作 | 申请试用 → 配合 POC 记录：热词、类目榜单、竞品销量这三类数据是否覆盖首批类目；能否导出；价格 → 决定是否订阅 |
| 交给系统 | 工具账号用于 R13 浏览器登录；无接口 |
| 未完成时 | 用拼多多前台网页读取（每日限量），需求侦察的数据量会少一些 |

### R11 生图服务 API

| 项 | 内容 |
|----|------|
| 操作 | 选 1–2 家支持「抠图 / 换背景 / 商品场景合成」的服务，注册并开通 API → 用 10 张货源图试做，比较效果与单价 → 设置用量上限 |
| 交给系统 | API Key；单张价格（用于成本计量） |
| 未完成时 | 只从素材库选图，程序做裁剪、加字 |

### R12 内网穿透（备用）

| 项 | 内容 |
|----|------|
| 何时办 | 仅在飞书卡片回调无法通过长连接接收时 |
| 操作 | 选一个内网穿透服务，获得一个固定的 HTTPS 地址，指向本机 web 进程端口；在飞书应用中把回调方式改为 HTTP 地址 |
| 交给系统 | 回调地址、飞书应用的 Verification Token / Encrypt Key |

### R13 浏览器登录（拼多多后台、1688、工具网页）

| 项 | 内容 |
|----|------|
| 前置 | R14 环境就绪、系统已安装 |
| 操作 | 运行系统提供的登录命令，会打开系统专用浏览器（和你日常用的 Chrome 隔离）：<br>1. 拼多多后台：用店铺主账号扫码登录<br>2. 1688：用 R02 采集账号登录<br>3. 市场数据工具、铺货代发工具：用各自账号登录<br>登录后关闭浏览器即可，会话会保存 |
| 日常 | 登录失效时系统会在飞书提醒，按提示重新扫码即可 |
| 注意 | 不要用这个专用浏览器做其他事；账号密码不录入系统 |

### R14 本地主机与运行环境

| 项 | 内容 |
|----|------|
| 主机 | 一台常开的 Windows 电脑，8 GB 内存以上，SSD 剩余 50 GB 以上 |
| 设置 | 关闭自动睡眠和休眠；Windows 更新设为非工作时段重启；网络稳定 |
| 软件 | Python 3.12、Chrome、Git（开发阶段由开发者安装） |
| 备份 | 准备一个备份目录（另一块盘或网盘同步目录） |

### R15 首批类目确定与店铺类目开通

| 项 | 内容 |
|----|------|
| 操作 | 1. 定 1–2 个首批类目，要求：无需特殊资质、不易侵权、体积重量适中、退货率不高（选品规则硬性过滤已排除食品、化妆品、母婴、3C 等需资质类目）<br>2. 在拼多多后台确认该类目可以发布，如需额外资质按页面要求办理 |
| 交给系统 | 类目名称（填入规则配置） |
