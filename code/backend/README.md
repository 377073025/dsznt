# 后端框架（M0–M1 骨架）

按 [07-系统详细设计](../../doc/07-系统详细设计.md) 搭建。所有外部依赖都有模拟实现，**不需要任何申请就能跑通整个闭环**；申请下来一项（见 [08-人工申请清单](../../doc/08-人工申请清单.md)），实现一个真实适配器、打开对应能力即可。

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\pip install -e .[dev]
.venv\Scripts\python -m pytest -q          # 163 个测试（需要 Python ≥ 3.11）
.venv\Scripts\python scripts\demo_run.py   # 演示：海盐换图闭环 + 周选品 + 上新，打印飞书卡片
```

正式运行（两个进程）：

```bash
.venv\Scripts\python scripts\init_db.py --shop "我的店" --owner-open-id ou_xxx
.venv\Scripts\uvicorn app.main:app --port 8000   # web：控制台 API + 页面 http://localhost:8000/
.venv\Scripts\python -m app.worker               # worker：调度 + 作业 + 事件
```

或者用看门狗一起启动（任一进程退出几秒内重启），并注册为登录后自启：

```bash
.venv\Scripts\python scripts\watchdog.py
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1   # 注册 Windows 计划任务；-Remove 卸载
```

日志：控制台为文本；`data/logs/web.log`、`worker.log` 为 JSON（每行一条，带 job_id / agent，按天滚动保留 30 天，token、手机号等自动打码）。
备份：worker 每天 03:00 把数据库快照与素材库增量备份到 `backup.dir`（默认 `data/backups`，建议改到另一块盘），保留 30 天。

`config/settings.yaml` 里 `adapter_mode: fake` 用模拟数据；改成 `real` 后，未实现或未就绪的能力会自动降级。

接入模型（R06）：默认用 DeepSeek（Anthropic 兼容接口），服务商、模型和价格在 `config/settings.yaml` 的 `llm`、`models`、`model_prices` 里改。在 Web「接入状态 → 模型服务 → 录入凭证」填凭证名称 `deepseek_api_key`（已预填）和 Key。DeepSeek 不支持结构化输出和 Batch：JSON 结构改写进系统提示词，诊断全部走实时调用。

接入生图（R11）：在火山方舟 Agent Plan 页面取套餐专属 API Key，到 Web「接入状态 → 生图服务 → 录入凭证」填写；地址和模型在 `settings.yaml` 的 `image_gen` 里改（按量付费用 `/api/v3`）。

接入飞书（R05 办好后）：在 Web「接入状态」录入凭证 `feishu_app_id`、`feishu_app_secret`，`adapter_mode` 改为 `real`，重启 worker。
worker 会在主线程跑飞书长连接（SDK 要求），作业循环在后台线程。机器人第一次在群里收到消息时，自动把该群设为推送群。
注意：导入飞书 SDK 本身约需 25 秒，worker 启动会慢一些。

## 目录

| 路径 | 内容 |
|------|------|
| `app/adapters/` | 外部依赖接口（`base.py`）与模拟实现（`fake.py`）：拼多多、1688、市场工具、铺货代发、生图、飞书、模型服务（含 Anthropic 实现） |
| `app/capabilities.py` | 能力开关：状态、健康检查、与申请编号 R01–R15 的对应 |
| `app/data/` | 通道路由（API → 网页 → 人工）、校验、入库、快照对比、人工导入、网页读取层（脚本、白名单、风控识别、AI 认路） |
| `app/rules/` | 纯函数：指标、异常检测、硬性过滤、利润、打分、测款判定 |
| `app/agents/` | 统一运行器（工具循环、结构化输出、数字一致性校验、运行记录）与运营 / CEO / 选品 / 执行智能体；`catalog.py` 是可单独调用的能力目录，`status.py` 计算各智能体当前状态 |
| `app/tools/` | 工具注册表：readonly / internal / shop 三级，写店铺前再校验写入确认 |
| `app/workflow/` | 状态机、领域事件、作业队列（主通道 / 单独通道）、编排、单独任务（`adhoc.py`） |
| `app/interfaces/feishu/` | 卡片、回调处理（3 秒内返回 + 异步执行）、通知、单独任务指令（`adhoc_commands.py`） |
| `app/interfaces/console_api.py` | Web 其余页面的接口：闭环总览、选品中心、任务看板、数据中心、规则配置（版本、调权提议）、成本、用户与权限、商品与素材 |
| `app/workflow/system.py` | Batch 轮询、预算告警、周度系统报告 |
| `app/workflow/on_sale.py` / `tuning.py` | 在售款：上新商品 ID 回填、货源每日复查 `offer_watch`；月度调权提议 |
| `app/logs.py` / `app/backup.py` | JSON 日志与脱敏、每日备份 |
| `app/main.py` / `app/worker.py` | web 与 worker 入口 |
| `app/static/` | Web 控制台（纯静态 HTML/JS，无构建步骤）：智能体工作台（`app.js`）与闭环总览、选品中心、任务看板、数据中心、规则配置、成本、商品与素材（含手工货源、素材缩略图）、用户与权限、接入状态（`pages.js`），按 `#/页面` 切换。右上角填飞书 open_id 作为身份（M3 接入飞书登录后替换） |
| `scripts/` | 初始化、演示、看门狗与开机自启 |
| `app/prompts/` | 各智能体提示词（带版本号） |
| `config/` | 设置、规则、平台、数据项定义 |
